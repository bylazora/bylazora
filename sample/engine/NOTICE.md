# The Bylazora engine

This directory contains the migrated application as a prebuilt binary for
Linux x86_64 (glibc). It implements the CPU tier and the vendor-neutral
wgpu GPU tier, and the byte-exact validator.

The binary is licensed under the Bylazora Commercial Licence (LICENSE.md):
free while you migrate (Developer tier, jobs up to 10 million rows each),
a Pro key to run in production or above the free cap, and an Enterprise
order form for estate programs and redistribution. The licence triggers on
production or scale, not on evaluation. Keys install offline
(bylazora-core licence set <key>, or BYLAZORA_KEY); the engine performs no
network I/O and sends no telemetry, so it runs air-gapped. For keys or
builds for other platforms, contact hello@bylazora.com.
